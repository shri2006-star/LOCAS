# LOCAS (Location-Based Operational & Customer Analytics System)

A full-stack application built with **React (Vite)** frontend and **Spring Boot (Maven)** backend.

## Project Structure

- `locas-frontend/` - React frontend application
- `locas-backend/` - Spring Boot backend API
- `seed_locas_database.sql` - Database initialization script

## Setup & Running

### Backend
Navigate to `locas-backend` and run:
```bash
mvnw spring-boot:run
```
Or run `START_LOCAS_BACKEND.bat`.

### Frontend
Navigate to `locas-frontend` and run:
```bash
npm install
npm run dev
```
